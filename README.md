# VEX IQ Event Timer

A super simple timer for timing a VEX IQ run and recording major events along the way — no more lap timers that are hard to turn into a spreadsheet.

**Live app:** https://tropicmango.github.io/vex-iq-event-timer/

## How to use

1. Press **Start** to start the run (60-second match bar shows time remaining).
2. Tap **Mark event** — or a quick chip like *Scored*, *Driver switch*, *Dropped piece*, *Robot reset*, *Stuck/recovered*, *Parked/hang*, *Foul* — when something happens.
3. Each event shows its time from the start and how long it took since the previous event. Event names can be edited after the run.
4. Press **Finish run** to save the run and start the next one.

## Export to a spreadsheet

- **Download CSV** — one row per event, with times in seconds and in `m:ss` format. Opens in Excel, Google Sheets, or Numbers.
- **Copy for Google Sheets** — copy the data and paste straight into a sheet.

Saved runs only live while the tab is open, so export before closing it.
